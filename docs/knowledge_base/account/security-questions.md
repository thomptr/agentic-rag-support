# Security Questions

## What Are Security Questions?

Security questions provide an additional identity verification layer used during account recovery scenarios (e.g., when you cannot access your email or MFA device). They are different from MFA — security questions are a supplemental verification tool, not a primary authentication factor.

## Setting Up Security Questions

1. Navigate to Settings → Security → Security Questions
2. Choose 3 security questions from the provided list
3. Enter your answers (answers are case-insensitive but must be exact)
4. Click "Save Security Questions"

**Available question categories**:
- Childhood memories (first school, childhood nickname, first pet)
- Preferences (favorite book, first car, favorite movie)
- Family (mother's maiden name, sibling's middle name)

## Security Question Best Practices

**Do**:
- Choose questions with answers that are stable over time (avoid "current favorite" questions)
- Use answers you will remember years from now
- Consider storing answers in your password manager
- Use a consistent capitalization/spelling convention

**Do not**:
- Use easily guessable information (common names, dictionary words)
- Use answers that are publicly available (social media, public records)
- Reuse security question answers from other sites

## When Security Questions Are Used

Security questions may be prompted during:
- Account recovery when email access is unavailable
- Identity verification by support agents for sensitive requests
- Password reset from an unrecognized device or location (as an additional step)

## Resetting Security Questions

To update your security questions:
1. Navigate to Settings → Security → Security Questions
2. Click "Update Security Questions"
3. Enter your current password to verify your identity
4. Select new questions and answers
5. Click "Save"

**Forgotten your security question answers?**
If you cannot answer your security questions for account recovery:
1. Contact account support
2. We will initiate an identity verification process (government ID required)
3. After verification, security questions are reset and you can set new ones
4. This process takes 24–72 hours

## Privacy and Security

**Important**: 
- Our support agents will NEVER ask for your security question answers over chat or email without a formal identity verification request in the support portal
- Never share your security question answers with anyone claiming to be from our support team outside of the official support portal
- If you receive a suspicious request for your security answers, report it to security@example.com
